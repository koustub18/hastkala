# HASTKALA
Arts & Handicrafts E-Commerce Platform
Team Alchemist — NIST University — TechSpire 1.0

## Project Structure
- client/ — React frontend (Vite)
- server/ — Node.js + Express backend

## Setup Instructions

### Server
cd server
npm install
Add .env file with MONGO_URI, JWT_SECRET, PORT
node server.js

### Client
cd client
npm install
npm run dev
